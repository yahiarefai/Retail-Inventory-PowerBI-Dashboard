# Retail Inventory Simulation & Analytics Dashboard

Interactive Power BI dashboard designed to analyze retail inventory performance, demand forecasting, product profitability, and regional/category insights using Power BI and Python.

---

## Project Overview

This project focuses on retail inventory optimization and business performance analysis through interactive dashboards and data visualization techniques.

The dashboard provides insights into:

- Revenue performance
- Inventory levels
- Demand forecasting
- Product profitability
- Regional inventory distribution
- Category-based revenue analysis

---

## Tools & Technologies

- Power BI
- Python (Pandas)
- CSV / Excel Dataset
- Data Cleaning & Transformation
- Data Visualization
- KPI Reporting
